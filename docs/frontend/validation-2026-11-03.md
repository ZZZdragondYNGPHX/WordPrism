## 模拟器上实际操作过的流程

| 流程 | 观察到的结果 |
| --- | --- |
| 今天页 | 计划、预算条、训练比例、重点辨析、AI 调整入口正常显示 |
| 学习会话 | 判断基础 → 看清差异（棱镜条分色）→ 选择题；选错时显示实际混淆词与复习影响 |
| 看提示后答对 | 显示“记为练习，不按无提示成功计入” |
| 进程被杀后恢复 | 学到第 4 题时切后台并 `am kill`，重新打开回到同一题；暂停后今天页显示“继续学习（已完成 3/11）” |
| 预算提示 | 接近预算后答完当前题才弹出；“再学一会儿”继续，提示不再重复 |
| 造句 + 缺少密钥 | 提交前提示预设缺少密钥；提交后句子保存，反馈任务失败并可重试；填写密钥（测试字符串）→ 保存后只显示末 4 位 → 连接测试（模拟）→ 返回重试 → 显示 AI 反馈 |
| 完成整轮 | 计划完成触发一次每日分析；分析产生调整记录 |
| AI 调整撤销 | 恢复新学上限，说明保留之后的作答；较早的调整重新可撤销 |
| AI 添加 | `linear 和 liner` 新建词组；`又遇到 linen…` 加入已有组并显示理由；回车键换行而不提交；退出后草稿恢复 |
| 离线 | 提交前提示会排队；任务显示“等待联网”；顶部离线横幅和任务数；恢复联网后自动完成，并复用已有的 `affect / effect` 组 |
| 词组编辑 | 移出成员 → 确认 → 撤销提示；接受推荐词（复用已有词条）→ 撤销 |
| 导出 / 导入 | 通过系统文件选择器导出完整备份到 Download；取出文件确认**不含**测试密钥；导入同一文件，预览模块与待配置项，确认后恢复；恢复后预设显示缺少密钥、每日分析为关闭 |
| 外观 | 深色模式、1.3 倍字体下今天页和词组页正常换行，无截断 |
| 无障碍节点 | uiautomator 检查：发现“AI 添加”悬浮按钮无标签（已修复）；棱镜条整体朗读为逐字母拼读及不同字母 |
