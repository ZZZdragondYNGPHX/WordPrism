# 设计依据

WordPrism 采用间隔练习、主动检索与围绕具体混淆的辨析。相关研究用于形成设计假设，项目的长期学习收益仍需验证。

| 依据 | 对设计的影响 | 来源 |
| --- | --- | --- |
| 间隔练习与检索练习 | 保存真实作答，安排延迟回忆，区分曝光与独立提取 | [R01–R05](sources.md#r01) |
| FSRS 与个人参数优化 | 调度、拟合和评估共用内核，样本不足时保留已有参数 | [R06](sources.md#r06)、[R49–R53](sources.md#r49) |
| 相关词学习可能产生干扰 | 以个人混淆与组内目的组织内容，观察新语境表现 | [R04](sources.md#r04)、[R05](sources.md#r05) |
| 结构化模型输出 | 使用类型化结果和业务校验，保留来源与内容版本 | [R21–R26](sources.md#r21) |
| Android 本地架构与恢复 | Room 持久化，WorkManager 唤醒，界面按稳定身份恢复 | [R36–R48](sources.md#r36) |
| 自适应教学与认知负荷 | 简短针对性解释、理解追问、自定速度和按需总结 | [R54–R60](sources.md#r54) |
| 原生界面与无障碍 | 清晰层级、足够触控尺寸、键盘可达与减少动态效果 | [R44](sources.md#r44)、[R61–R63](sources.md#r61) |

[完整来源](sources.md)保留论文、官方文档和候选产品链接。实际采用的依赖及许可见[第三方声明](../../core/third-party/wordprism-notices/README.md)。
