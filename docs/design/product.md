# 产品定位

WordPrism 帮助学习者分清自己经常混淆的英语单词，并在新语境中正确使用。词库以个人问题为起点，结合拼写、义项、搭配和实际错选记录组织训练。

## 核心流程

1. 输入易混词或导入内容包，形成可编辑的词条与词组。
2. 理解基本义和差异，再通过辨认、回忆、阅读和表达练习。
3. 保存真实作答，由 FSRS 安排复习。
4. 查看学习总览；启用 AI 时，由分析结果调整学习计划和训练组合。

## 数据组织

词条、义项、组关系和学习目标各有稳定身份。同一词可属于多个组；基础释义共享，组内辨析分别保存。孤立单词也可直接学习，之后再添加关系。

组关系包括形似、近义、构词、音似和个人易混。相似词形成候选，用户的实际混淆和组内目的决定关系的意义。

## 日常使用

默认日预算为 30 分钟，优先记忆质量。计划结合到期目标、实际用时和近期表现安排，允许减少新学或提前结束。

普通模式提供完整词库管理；AI 托管模式聚焦添词和背诵，两种模式共用数据。AI 负责内容生成与教学建议，学习记录、评分和策略应用由本机核心维护。

## 运行方式

Android 原生界面，本机存储与离线学习；AI 请求直连用户配置的服务。资料通过 `.wordprism` 内容包或完整备份携带。
