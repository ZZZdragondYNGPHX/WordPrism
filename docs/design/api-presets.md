# API 预设与功能分配

一个预设保存服务地址、协议、模型、请求参数和本机凭证引用。多个功能可以共用默认预设，也可以各自绑定模型；所有请求由手机直接发出。

## 配置

支持 Chat Completions 兼容接口与原生 Responses。模型可手动填写或从服务商列表选择，思维程度、输出上限和超时按预设保存。接口字段和映射见[API 协议](../backend/api-protocols.md)。

密钥使用 Android Keystore 保护的本机存储；读取预设只返回凭证状态。保存是本地操作，连接测试会调用所选模型。

## 功能分配

可为添词、推荐、讲解、练习生成、表达反馈、学习分析和随身助教分配预设。功能优先使用独立绑定，其次使用默认预设；缺配置时保留待配置任务。

## 调用由用户控制

| 操作 | 调用规则 |
| --- | --- |
| 查看词库、统计、已有题目和推荐 | 读取本机内容 |
| 拉取模型 | 请求一次服务商目录，取消或失败后可手动重试 |
| 添词、生成、助教提问、分析或连接测试 | 按本次操作创建对应请求 |
| 选择额外推荐词 | 复用已有内容，必要时生成补充内容 |
| 每日分析和托管准备 | 按启用模式、能力锁和调用额度执行 |
| 分析后补题 | 使用练习生成预设，计入总请求额度；通过能力锁控制 |
| 重试与备用预设 | 使用已配置策略；结果未知时由用户明确重试 |

查看任务可了解使用的预设、状态及已知用量。应用按请求设置执行，服务商支持的档位与额度由其接口决定。

## 任务版本与恢复

任务保留实际使用的预设版本。运行期间编辑配置影响后续任务；明确重试捕获当前保存版本，每次尝试的来源与用量分别保留。

完整备份保存非敏感配置、功能绑定和调用历史。恢复后重新填写密钥，按需要开启自动功能；未完成任务先进入待处理状态。
