# 数据格式与恢复

WordPrism 使用 `.wordprism` 文件携带词库和学习资料。文件是带版本清单的 ZIP 容器，包含 `manifest.json` 与 `modules/<name>.json`。

## 内容包与完整备份

| 用途 | 数据与导入方式 |
| --- | --- |
| `CONTENT` 内容包 | 词条、义项、组关系与相关内容，追加到当前词库 |
| `BACKUP` 完整备份 | 词库、学习历史、调度、分析、非敏感 API 配置和任务，替换恢复资料库 |

完整备份包含 `library`、`learning`、`memory`、`analysis`、`api`、`operations` 六个模块。凭证、设备文件权限和系统后台句柄在新设备重新建立。

## 版本与兼容性

清单记录格式版本、生产者、包及资料库身份、模块 schema、依赖和 SHA-256。当前容器版本为 `1`，已知模块 schema 为 `2`。

已支持的旧版本按迁移路径读取；未知可选模块或字段保留，未知必需模块、过新的已知模块或非法引用返回兼容性错误。详细结构见[schema](../core/schemas)与[格式实现](../../core/core-engine/src/main/kotlin/dev/wordprism/engine/Packages.kt)。

## 导入与恢复行为

1. 读取清单，检查版本、完整性、依赖和资源规模。
2. 展示用途、新增、重复、冲突与待配置项；预览绑定当前资料库修订。
3. 内容包追加，完整备份在校验后事务替换；冲突需修正来源后重新导入。
4. 保存实际导入结果；相同身份的内容重复导入保持一致。

完整恢复保留原始身份和学习历史，重新配置凭证，关闭自动调用，并将未完成任务置为待处理。普通应用重启继续使用本机已保存设置。

Android 通过系统文件选择器读写流。导出收据用于重复提交去重，文件提供方与数据库之间的中断恢复规则见[文件契约](../core/contract.md#文件与凭证)。
