# 学习总览与 AI 调整

学习总览与 AI 分析使用同一份核心快照。快照由作答、用时、任务和策略记录计算，分析结果可包含学习计划、内容或参数变更。

## 个人目标与动态预算

默认日预算为 30 分钟，由用户修改。计划在剩余预算内优先安排复习，结合目标类型与近期有效用时估计数量；接近预算时完成当前题，再选择结束或继续。

到期任务较多时可减少新学，理解或表达任务耗时较长时可缩短队列。用时按日累计，学习、生成等待和后台分别记录。计时细节见[核心契约](../backend/contract.md#学习反馈与撤销)。

## 同一份事实供用户和 AI 使用

| 内容 | 展示口径 |
| --- | --- |
| 投入与完成 | 实际学习时间、完成目标及计划版本 |
| 记忆表现 | 有条件的作答结果、延迟回忆和新语境表现 |
| 混淆关系 | 实际错选方向、目标与相关证据 |
| 表达能力 | AI 用词评价，与客观评分分开 |
| 负担预测 | 当前调度与个人用时估计，标明样本情况 |
| API 使用 | 实际尝试、预设版本及供应商已报告用量 |

快照保留截止时间、覆盖记录与计算口径。分析可以继续查询相关证据，已有分析保留其原始依据。

## 可调整范围

AI 通过能力目录调整新学量、目标优先级、训练组合、适用的记忆设置，并准备讲解或练习。用户可锁定项目；日预算、请求额度和明确功能绑定优先。

实际作答、凭证和额外推荐词的接纳由各自业务入口管理。变更显示前后值、依据与生效时间。

## 算法微调的执行方式

调度、拟合和评估共用本机 Rust FSRS 内核。使用带目标、时间和评分来源的真实历史拟合，按时间切分评估候选；数据不足时保留已有参数。

拟合采用单线程、样本和时长预算，可取消。参数模型和策略版本与记录一起保存，具体上限见[运行边界](../backend/running.md#运行边界)。

## 生效时间与撤销

提交变更时检查配置版本与任务状态，作用于适用的后续计划。撤销是补偿操作：恢复内容或策略，并保留后续作答；需要重算调度时使用完整有效历史。

## 每日分析与手动控制

完成当日计划或明确结束当天后创建自动分析任务；普通模式的暂停与单轮结束仅保存会话。托管模式采用[学后分析规则](mobile-learning.md#ai-托管模式)。

| 情况 | 行为 |
| --- | --- |
| 同日重复结束、重启或重试 | 按学习日及证据身份复用任务 |
| 手动分析 | 使用当前快照；相同有效证据可复用结果 |
| 没有新的有效证据 | 保留原策略，不重复应用旧分析 |
| 关闭自动分析 | 取消排队任务，使在途自动结果失去提交资格；保留已生效变更 |
| 断网或配置缺失 | 保存待执行状态，继续使用当前计划 |
| 跨日积压 | 合并过期任务，分析最新证据，保留触发日与执行日 |
| 无效参数或并发冲突 | 保留当前有效配置，返回任务结果 |

延迟执行占用实际执行日的自动名额。手动入口在自动分析关闭时仍可使用，查看总览和已有结果使用本地数据。
