# AI 添加与归组

在 AI 添加入口输入 `linear 和 liner，我总是搞混`，应用检索本地词条和相关组，再由模型生成结构化内容。简短词列同样可用。

## 添加与归组

| 情况 | 行为 |
| --- | --- |
| 已有词条或相同词组 | 优先复用内容和身份 |
| 明确指定已有组 | 添加关系，保留原词条、笔记和进度 |
| 有明确匹配关系 | 加入相应组，显示结果与归组说明 |
| 新的一组易混词 | 创建可编辑的词组 |
| 孤立单词 | 保存为可独立学习的词条 |
| 拼写或归属有歧义 | 普通模式提供选择；托管模式保留原拼写并使用个人组 |

形似、近义、构词、音似和个人易混是不同关系。同一基础词条可参与多个组，组内辨析分别保存。用户可手动编辑成员或撤销添加。

添加经过词条、引用、关系与题目结构校验后统一保存；结果包含实际新增、复用与归组内容。接口见[核心契约](../core/contract.md#已接入的业务接口)。

## 额外词推荐与加入

已有候选可直接查看；点击“寻找更多”才发起新推荐请求。用户选择额外词后，完整内容可本地复用，需要补充时使用对应预设生成。

加入完成后可撤销，保留其他组引用和后来发生的学习。未选择候选继续保留在推荐中。托管和分析功能遵循同一规则。

## 词源与助记

讲解按稳定义项保存，包含中文解释、英英释义、构词、词源、助记、用法和例句。构词分析、历史词源与记忆联想分开标识，AI 内容可编辑和重新生成。

有效讲解可用于后续练习与分析；义项修改后旧讲解标为待更新。词族候选通过同一个推荐接纳入口加入。类型、来源和版本规则见[讲解接口](../core/explanations.md)。

## 导入与学习

`.wordprism` 内容包经预览后追加词条和关系；导入本身不请求模型。完整备份按[恢复规则](native-format.md)处理。

新内容按日计划逐步安排，新增关系只创建必要的学习目标。修改说明或例句保留已有学习历史。

## 重复操作与失败处理

输入草稿、任务和已保存结果分别持久化。重复提交复用请求身份；取消在业务提交前生效，已完成的操作可按规则撤销。迟到结果保存前检查目标版本与任务状态。

超时、限流、截断和配置错误保留输入与任务，可在修正预设后重试。等待生成期间仍可编辑词库和进行已有练习。具体重试与用量行为见[API 协议](../core/api-protocols.md#失败取消与用量)。
