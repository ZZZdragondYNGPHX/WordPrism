# 手机学习与 AI 训练

学习围绕稳定的词条、义项和混淆目标展开。新题可以改变语境和问法，同一目标的学习历史持续累积。

## AI 托管模式

首次配置 API 后，日常以添加词组和背诵为主。应用复用已有内容，按近期添加与当天计划准备讲解和练习，并在学后分析表现。

- 未设置默认预设时，选择第一份已启用且有凭证的预设，保留已有功能绑定。
- 添加时保留原拼写；归组不明确时保存为个人组，额外推荐仍由用户选择加入。
- 准备任务最多同时保留两项，遵守能力锁和每日请求额度。
- 讲解出现在基本义与辨析阶段，作答时隐藏；离线可学已保存内容。
- 有新作答的会话暂停、退出或完成后触发学习日分析，每天最多自动分析一次。跨日恢复会处理未结束的旧学习日。
- 切回普通模式会取消未完成的托管自动任务，保留普通模式的偏好。完整备份恢复后先使用普通模式。

实现入口见[托管契约](../backend/contract.md#学习模式与托管执行)。

### 随身助教

“问助教”使用当前题目、答案和近期对话；一轮暂停或完成后，点击“本轮助教总结”才请求总结。相同会话记录复用已有任务或结果。

提交前求助会登记辅助曝光，回复不阻塞继续学习。助教观察引用有效作答及其版本，可供后续讲解、出题和分析使用；答案修订或争议会使相关旧观察失效。

助教可建议当前会话未完成目标的顺序；已切换题目后到达的建议不再重排。学习量和记忆参数由每日分析路径调整。

## 一次手机学习

1. **开始或继续**：按当日剩余预算安排到期复习和新学；同日中断按原题续接。
2. **理解差异**：判断熟悉程度，阅读基本义、关键字母和用法对照。
3. **独立作答**：隐藏解释与高亮，完成当前目标的题目。
4. **得到反馈**：客观题立即反馈；开放表达先保存原答案，可继续学习并稍后查看 AI 评价。
5. **暂停或结束**：普通模式中暂停只结束会话；计划完成或明确结束当天时进入日终分析。

孤立单词支持基本义学习。引导模式下首次答错的目标在本轮末尾最多辅助巩固一次，复用已有内容。导入新词后由日计划逐步安排。

## 训练方式

| 方式 | 目标 |
| --- | --- |
| 词形与词义辨认 | 认识单词、分清字母结构 |
| 短句选词 | 判断具体义项、搭配与语境 |
| 无选项回忆 | 主动提取词形与词义 |
| 短文理解 | 在新语境中辨析含义 |
| 造句与改写 | 主动使用目标词，获得表达反馈 |

训练比例随计划调整。生成内容使用已有义项、实际混淆、近期题目和有效讲解；题目版本与答案依据随作答保留。

## AI 训练与内容变化

讲解、答案曝光和无提示作答分别记录。练习通过变化句子、选项和提问方式减少对固定题面的依赖；短文围绕适量目标词展开。

已有题目可重复使用，新的生成等待联网。开放反馈绑定原答案版本，修改答案后旧反馈仍保留为历史。调用规则见[API 预设](api-presets.md#调用由用户控制)。

## 作答与评分

| 行为 | 记录与调度 |
| --- | --- |
| 无提示完成可判定题 | 保存答案与目标，按评分映射更新调度 |
| 选错或忘记 | 对被测试目标记失败，记录实际混淆方向 |
| 答对但困难 | 保留成功结果和困难反馈 |
| 提示、看答案或辅助巩固 | 作为练习记录，与独立回忆分开 |
| 开放表达的 AI 评价 | 按目标词用法与表达维度反馈，独立于 FSRS 评分 |
| 多个合法答案 | 接受题目定义的合理选项 |
| 题目争议 | 隔离受影响结果，按纠正规则重新计算 |
| 跳过或中断 | 保留会话状态 |

## 输入与恢复

作答提交、进度与调度一起持久化。重复提交只产生一份有效结果，草稿与已提交答案分别保存。页面重建按会话和题目身份恢复。

输入框支持正常 IME 编辑，明确按钮提交使用当前可见文本。切题和编辑即时响应，反馈动画不锁住操作；界面适配键盘、字体缩放和关闭动画设置。
